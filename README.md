# Form đăng ký với Bootstrap

Mở `index.html` bằng trình duyệt có Internet để tải CSS Bootstrap 5.3.0 qua CDN.

## Trường dữ liệu

Họ và tên, email, mật khẩu, xác nhận mật khẩu, giới tính (radio), sở thích (checkbox), quốc gia (select) và nút Submit.

Sử dụng form-control, form-select, form-check, btn-primary, text-muted, text-center và Bootstrap Grid để bố trí hai ô mật khẩu cạnh nhau từ 768px, xếp dọc trên mobile.

## Kiểm tra dữ liệu

- Trường bắt buộc, định dạng email và mật khẩu tối thiểu 8 ký tự được kiểm tra bằng HTML.
- JavaScript kiểm tra xác nhận mật khẩu trùng khớp.
- Submit hợp lệ hiển thị thông báo minh họa, không gửi hoặc lưu dữ liệu, không tạo tài khoản thật.
- Không đưa mật khẩu vào URL, log hoặc nội dung thông báo.
